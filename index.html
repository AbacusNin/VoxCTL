Performance

Cents repeat every octave. Example quarter-tone scale: 0, 50, 100 … 1150. Up to 128 degrees.

The tuner under the scope shows the sung pitch against the nearest semitone of the reference, before quantizing. Hysteresis holds free-mode pitch until the voice moves further than the setting. It also removes vibrato shallower than the setting, turns slow slides into steps, and can leave a held note up to that far off. 0 is off. Quantized mode has its own hold.

Synth

Times are to about 95 percent. Release also slows the voice getting quieter, not only the note end. The feedback guard mutes on its own fast path, never at the release time. Below 1 the curve lifts quiet singing; above 1 it saves the full level for loud singing.

INTEROPERABILITY

MIDI

Pick a slider, press Learn CC, then move a knob or fader. CCs 0 to 119 on any channel can bind; the slider jumps to the knob. Bindings are saved in this browser.

Optional. MIDI access is requested only when you connect it.

SYNTH BUS

Recorder / looper

Takes record the synth only. Loop playback, the click and the count-in are not recorded.

On speakers, loop playback and the click feed the mic, and while a loop plays the feedback guard cannot catch the synth either. Loop on headphones. The loop is fitted to the bars by changing its speed, which changes its pitch too. Loop offset shifts a grid take earlier (positive) or later against the click, on top of the latency estimate.

Records the synth output, not raw microphone audio.

Commands

Optional. Continuous theremin control does not depend on speech recognition.

Privacy: while spoken commands are on, the browser streams your microphone to its speech service. Chrome sends it to Google's servers and Edge to Microsoft's. The theremin audio path itself never leaves this device.

API v0.3

Plugins

Only bundled, reviewed modules run trusted in the page realm. Isolated control plugins run in a sandboxed iframe, talk to the host only over a private message port, and can only request the capabilities their manifest lists.

PERFORMANCE TELEMETRY

Latency estimate

Estimated voice-to-sound delay from values the browser reports plus the pitch window. Not a measured round trip. A + means some values were not reported, so the real figure is higher.
